# NexKey Data Sources

All word lists, frequencies, character mapping tables, and phonetic rules used in NexKey are derived from open, public domain, or permissively licensed corpora:

1. **Bangla Phonetic Rule Set & Layout Maps**:
   - Constructed from standard Unicode Bengali block specifications (Unicode 15.0/16.0).
   - Phoneme-to-grapheme mappings constructed from standard IPA phonetic rules for Bengali.
2. **Bangla Word List & Frequencies**:
   - Derived from public domain Bangla Wikipedia dumps and open linguistic datasets.
3. **English Word List & Frequencies**:
   - Derived from public domain word lists (Google 10,000 English words corpus / SCOWL open dictionary).
4. **Emoji & Unicode Metadata**:
   - Unicode Consortium CLDR (Common Locale Data Repository) v44+ emoji annotations.
