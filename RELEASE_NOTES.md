# NexKey Keyboard v1.2.0 - Release Notes

## Overview

NexKey Keyboard v1.2.0 brings **emoji search**, **recent emoji persistence**, **compact search keyboard**, and several quality-of-life improvements to the emoji experience.

## Highlights

- **Emoji Search** — Type to find any emoji instantly; 400+ keywords mapped across all categories
- **Horizontal Scrollable Rows** — Search results display in independently scrolling rows (configurable 1–2 rows)
- **Compact Keyboard** — Keyboard shrinks during search to show more results without hiding the keyboard
- **Blinking Cursor** — Visual cursor in the search bar so you always see where you're typing
- **Recent Emoji Retention** — Recently used emojis are remembered; configurable from 1 day to forever
- **GIF/Sticker Tabs** — Tab bar in emoji panel (GIF and Sticker support coming soon)
- **Speed Meter Fonts** — Choose from 4 font styles (DIGITAL, LCD, SEGMENT, MODERN)

## What's New in v1.2.0

### Emoji Search
- Tap the search bar in the emoji panel to activate search mode
- Type using the main keyboard — results appear in real-time above the keyboard
- Each row scrolls left-right independently to show all matching emojis
- Close button exits search and restores your previous keyboard mode

### Emoji Search Settings
- **Horizontal scroll** — ON = rows scroll left-right (default), OFF = vertical grid
- **Visible rows** — 1 or 2 rows shown (only available when horizontal is ON)

### Recent Emoji Retention
- Recently used emojis are saved with timestamps
- Configurable expiry: 1 day, 7 days, 30 days (default), 90 days, or forever
- Found in Settings → Emoji

### Keyboard Improvements
- Keyboard automatically shrinks to 65% height during emoji search
- Switching keyboard modes (via toolbar) closes emoji search automatically
- Closing search restores your previous keyboard mode (English/Bangla/etc.)

### Emoji Panel
- GIF and Sticker tabs added (placeholder for future support)
- Delete/backspace button in the category label row
- Emoji category icons replaced with standard Material Icons

## Fixes
- Popup candidates no longer expand keyboard to full screen
- Removed duplicate clear/close buttons in search bar — single "Close" button
- Keyboard no longer stays in compact mode after switching modes
- Mode properly restores after closing emoji search
- Removed deprecated offensive word filtering
- CI signing config compatibility fix
